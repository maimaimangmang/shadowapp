## 发布前手工验收

- [ ] 在启动器内启动空间 A，登录账号 A，完成一条简单任务。
- [ ] 完成 A 的登录后，再启动空间 B，明确选择不同账号 B，完成任务。
- [ ] 保持两个窗口同时运行，确认账号与会话列表各自正确。
- [ ] 连续点击已运行账号的按钮，应切换同一个实例，不应不停新建进程。
- [ ] 在启动器中正常退出 A，确认 B 仍然可用。
- [ ] 重新启动 A，确认仍保留 A 的登录与历史。
- [ ] 退出并重开启动器，确认能识别、聚焦此前运行的 A/B。
- [ ] 在 A 的 Codex 窗口里退出登录，确认 B 不受影响。
- [ ] 停止一个测试空间后移至废纸篓，确认另一个空间和默认 Codex 数据未变化。
- [ ] 升级 Codex 后重新执行以上检查，并记录版本。
