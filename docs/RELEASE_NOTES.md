# Codex Multi v0.1.0 — Preview

一个用于在 Mac 上同时运行多个 Codex 账号空间的原生启动器。

- 添加、重命名账号空间；独立保存状态。
- 从主界面或菜单栏打开账号、切换到现有窗口。
- 单独请求退出已确认的实例，将停止空间移至废纸篓。
- 自动检测已安装 Codex，启动前进行静态兼容性检查。
- 中文 / 英文界面；无第三方 Swift 包依赖。

已在 Apple Silicon、macOS 26.5.2、Codex 26.901.51231 上验证新增与重命名、两个独立实例启动、窗口切换、单独退出，以及管理器重开后识别原实例。13 项核心检查通过。

## 安装与试用

1. 下载下方 `Codex-Multi-0.1.0-arm64.zip`，用于 M 系列芯片 Mac。
2. 解压并打开 `Codex Multi.app`。需要先自行安装 Codex 桌面应用。
3. 打开「个人账号」，完成第一个账号的登录；再打开「工作账号」登录另一个账号。
4. 两个窗口名称仍会沿用 ChatGPT / Codex，请通过登录邮箱确认账号不同。

此应用采用临时签名，尚未经过 Apple 公证。macOS 如果阻止打开，请在确认来源后通过「系统设置 → 隐私与安全性」批准，或自行从源码构建。附带 `.sha256` 文件用于校验下载完整性。

## 当前限制

- 这是公开试用的预览版，使用了尚未公开的桌面数据目录参数，Codex 更新可能影响兼容性。
- 两个真实账号同时登录、以及在一个窗口退出登录后另一个是否保持可用，仍需人工验收；已验证的多实例运行流程不等于完整账号隔离保证。
- Intel 启动器可交叉编译，但尚未在 Intel Mac 和兼容的 Codex 版本上实测，本次只提供 Apple Silicon 应用包。

欢迎在 Issues 反馈系统版本、Codex 版本和复现步骤。不要上传登录凭据、`auth.json` 或完整账号数据目录。

独立社区项目，与 OpenAI 无隶属关系。不包含或重新分发 Codex 桌面应用。
